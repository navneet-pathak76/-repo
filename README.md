# RP Exchange Android App

Expo React Native prototype based on the supplied reference screenshots.

## Included
- Home dashboard
- Balance and invite code
- 3-level rebate banner
- Buy RP / Sell RP screens
- INR/USDT calculator
- Mine/profile
- Bottom navigation
- Reference-style mobile UI

## Development
npm install
npx expo start

## Planned backend
Firebase Authentication, Firestore, Storage and private APK distribution can be added next.

This prototype does not execute real crypto transfers or custody funds.
